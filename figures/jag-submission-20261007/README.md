# JAG submission figures

This directory contains the final figure set for the Journal of Applied Geophysics submission dated 2026-10-07.

- `Fig1.tif`–`Fig9.tif`: main-manuscript figures.
- `FigS1.tif`–`FigS2.tif`: supplementary figures.
- `*_preview.png`: lightweight review copies for selected revised figures.
- CSV files: non-sensitive aggregate/source summaries used in the added diagnostics.
- `FIGURE_MANIFEST_SHA256.csv`: file hashes and provenance scope.

The plotting script in `figure_scripts/make_jag_submission_figures.m` requires authorized proprietary inputs and the full local run archive. Those inputs and row-level predictions are intentionally excluded from this public repository. No model was refit for figure generation.
